# Screenshot checklist

Take each screenshot yourself; no images are generated by automated tests.
For every page, capture the browser at a normal desktop viewport and again at
**375 CSS pixels wide**. Ensure the page is fully loaded, charts have rendered,
and the language shown matches the filename. Do not expose credentials, email
addresses, or other personal information.

Use the saved UI-language preference to capture each language. Use a seeded
prediction for results and at least one saved row for history.
